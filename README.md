# Xingjiang Lin - Personal Homepage

Source for https://linxingjiang.github.io, built with Jekyll from the
[academic-homepage](https://github.com/luost26/academic-homepage) template.

- Profile, education and experience: `_data/profile.yml`
- Projects: one file per project in `_projects/` (copy `_projects/_TEMPLATE.md`)
- News: `_news/`, blog posts: `_posts/`

Local preview: `bundle exec jekyll serve`, then open http://127.0.0.1:4000.
Pushing to `master` deploys via GitHub Actions.
